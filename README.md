# 认知翻译 · 把难懂的话翻译成人话

> 把世界上难懂的话，翻译成每个人都能真正看懂的话——并告诉你下一步该做什么。

## 在线使用

打开：**https://z9cwwf48w4-lab.github.io/cognitive-translate/**

- **不配密钥**：内置财经/AI 高频词“卡点词库”+ 8 句深度翻译示例，可直接体验（离线可用）。
- **配密钥（可选）**：点「AI 设置」，填入你自己的 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 创建），**任意句子**都能翻译成四段式：30 秒看懂总结 → 生活例子 → 为什么重要 → 下一步；还支持“换个说法”和 AI 识别卡点词。

> 隐私：选中的文字只发送给你填写的模型服务商用于翻译；密钥只存在你自己的浏览器本地；本站没有服务器、不收集任何内容。

## 浏览器插件（Chrome / Edge）

1. 下载本仓库 `extension/` 文件夹（或 [认知翻译-原型/插件] 中同款）。
2. 打开 `chrome://extensions`（Edge：`edge://extensions`）→ 开启右上角“开发者模式”。
3. “加载已解压的扩展程序” → 选择 `extension/`。
4. 在任意网页选中文字 → 右键 → 「认知翻译：把这段话翻译成人话」。

（上架 Chrome 应用商店的流程已备好，按需发布即可让普通用户一键安装。）

## macOS 全局划词（阅读器 / PDF / AI 工具等任何软件）

按仓库内说明创建“快速操作”：选中文字 → 右键 → 服务/快速操作 → 认知翻译，即调用本公网页面翻译。也可绑定快捷键。

## 文件说明

- `index.html` — 单文件应用（词库 + AI 模式都在里面，可整站复制到任意静态托管）。
- `extension/` — Chromium 划词插件。
